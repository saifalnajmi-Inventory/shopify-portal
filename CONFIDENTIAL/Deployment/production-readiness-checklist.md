# Production Readiness Checklist — CONFIDENTIAL
## Complete before giving any client access

---

## 1. Environment Variables

- [ ] `SHOPIFY_STORE_DOMAIN` is set (e.g. `yourstore.myshopify.com`)
- [ ] `SHOPIFY_ACCESS_TOKEN` is set (starts with `shpat_`)
- [ ] `DATABASE_URL` points to PostgreSQL (production) or SQLite (dev only)
- [ ] `INTERNAL_SYNC_KEY` is set (auto-generated by seed script)
- [ ] `NODE_ENV=production` is set on the server
- [ ] `.env.local` is NOT committed to git (check `.gitignore`)
- [ ] No credentials appear in any page/*.js file (only pages/api/*)

**How to verify:**
```bash
grep -r "SHOPIFY_ACCESS_TOKEN" pages/*.js  # Should return nothing
git status --ignored | grep .env           # Should show .env.local as ignored
```

---

## 2. HTTPS / SSL

- [ ] Domain is registered and pointed to server IP
- [ ] SSL certificate is issued (Let's Encrypt via Coolify or Certbot)
- [ ] All HTTP traffic redirects to HTTPS
- [ ] Cookies have `Secure` flag (auto-enabled when NODE_ENV=production)
- [ ] Test: `curl -I http://yourdomain.com` → should redirect to HTTPS

---

## 3. Database

- [ ] PostgreSQL is running (not SQLite in production)
- [ ] `prisma db push` or `prisma migrate deploy` ran successfully
- [ ] Admin user seeded: `node scripts/seed-admin.js`
- [ ] Automatic backups enabled (Hetzner snapshots or pg_dump cron)
- [ ] Test restore from backup before going live

**Backup command example:**
```bash
pg_dump $DATABASE_URL > backup_$(date +%Y%m%d).sql
```

---

## 4. Auth & Security

- [ ] Admin password changed from `admin123` immediately after first login
- [ ] Login works: go to `/login`, enter credentials, verify redirect to dashboard
- [ ] Logout works: click logout button, verify redirect to `/login`
- [ ] Session persists across page refreshes
- [ ] Session expires correctly after 30 days
- [ ] Accessing `/` without login redirects to `/login`
- [ ] Accessing `/api/dashboard` without login returns 401
- [ ] Accessing `/api/sync` without login returns 401

---

## 5. RBAC Testing

### Viewer role test:
- [ ] Create a viewer user in `/users`
- [ ] Log in as viewer
- [ ] Verify: can see dashboard, products, notifications
- [ ] Verify: "Sync from Shopify" button is NOT visible in sidebar
- [ ] Verify: `POST /api/sync` returns 403
- [ ] Verify: `POST /api/quickpush` returns 403
- [ ] Verify: cannot access `/users` page (redirects to `/`)

### Manager role test:
- [ ] Create a manager user
- [ ] Log in as manager
- [ ] Verify: "Sync from Shopify" button IS visible
- [ ] Verify: can push inventory changes
- [ ] Verify: cannot access `/users` page
- [ ] Verify: `PUT /api/settings` returns 403

### Client Admin test:
- [ ] Create a client_admin user
- [ ] Log in as client_admin
- [ ] Verify: can access `/users` page
- [ ] Verify: cannot see `super_admin` role in Add User form
- [ ] Verify: cannot sync or push

---

## 6. Shopify Integration

- [ ] Shopify token has required scopes: `read_products`, `read_orders`, `read_inventory`
- [ ] Manual sync completes without errors
- [ ] Products load in dashboard after sync
- [ ] Quickpush (update stock) works end-to-end
- [ ] Autosync runs on startup and every 6 hours

---

## 7. Audit Logs

- [ ] Login creates AuditLog entry
- [ ] Logout creates AuditLog entry
- [ ] User creation creates AuditLog entry
- [ ] Verify in DB: `SELECT * FROM AuditLog ORDER BY createdAt DESC LIMIT 10;`

---

## 8. Client Access Verification (Final Check)

- [ ] Client receives: URL only + username + password
- [ ] Client cannot access: `/api/*` directly without session cookie
- [ ] Client cannot access: source code, GitHub, server
- [ ] Client cannot access: `.env.local` or any environment variables
- [ ] Client cannot access: Shopify Access Token
- [ ] All write operations (sync, push) are logged via AuditLog or ChangeLog

---

## 9. Backup & Recovery

- [ ] Backup script runs daily (cron or Hetzner snapshot)
- [ ] Test restore: restore backup to a test DB, verify data
- [ ] Recovery time objective: can restore in < 30 minutes
- [ ] Backup retention: keep last 7 days minimum

---

## 10. Go-Live Checklist

- [ ] All above items checked
- [ ] Admin password changed
- [ ] Client user created with appropriate role
- [ ] Client tested login successfully
- [ ] You have SSH/admin access to server
- [ ] Monitoring alert set up (BetterStack or UptimeRobot — free)
- [ ] You have a support channel for the client (WhatsApp, email)
